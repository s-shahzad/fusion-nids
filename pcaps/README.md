# pcaps/

Replay material for the detection pipeline. Seven bundles are tracked here so
that the validation claims in this repository can be reproduced by someone who
is not the author — which is the point of the project.

## Why these are tracked

They are **synthetic**. Every bundle is generated by this repository's own
`src/nids/adversary_lab/scenarios/` modules, against mock targets, under an
`offline-replay-only` safety policy. Each carries scenario IDs (`ADVLAB-00x`)
and labels marked `lab_generated:`.

**No third-party network was captured.** Nothing here describes the security
posture of an organisation other than this project's own lab. That distinction
is why these are published while other scan material is not — see
[Known Limitations](https://github.com/s-shahzad/fusion-nids/wiki/Known-Limitations).

Total size is about 296 KB, so tracking them costs the repository almost nothing.

## The bundles

| Directory | Scenario | What it exercises |
|---|---|---|
| `port-scan-pattern-labdemo/` | ADVLAB-001 | Low-noise TCP SYN sweep, scan-threshold validation |
| `bruteforce-login-pattern-labdemo/` | ADVLAB-002 | Repeated login attempts |
| `beaconing-pattern-labdemo/` | ADVLAB-003 | Periodic callback traffic |
| `exfiltration-pattern-labdemo/` | ADVLAB-004 | Outbound volume anomaly |
| `lateral-sequence-pattern-labdemo/` | ADVLAB-005 | Internal movement sequence |
| `protocol-anomaly-pattern-labdemo/` | ADVLAB-006 | Malformed or off-spec protocol behaviour |
| `campaign-chain-pattern-labdemo/` | ADVLAB-007 | Multi-stage chain across several of the above |

Each contains the capture plus `labels.csv`, `manifest.json`,
`normalized_events.jsonl`, `suricata_eve.jsonl`, `zeek_conn.jsonl`, and a
`README.md` with the exact replay commands.

## Replaying one

```sh
python -m nids run \
  --pcap-dir pcaps/port-scan-pattern-labdemo/port-scan-pattern.pcap \
  --labels   pcaps/port-scan-pattern-labdemo/labels.csv \
  --config   lab/config/offline_replay_profile.yml \
  --rules    rules/rules.yml \
  --output-dir output/port-scan-replay \
  --sensor-id adversary-lab
```

Suricata- and Zeek-adapter variants are in each bundle's own README.

## Guardrails

These are emulation artefacts. Replay them offline, against localhost, in a
container, or inside an explicitly isolated lab CIDR. Do not direct them at any
live external target.

Real captures are **not** tracked. `lab/pcaps/` is gitignored, and anything
containing third-party traffic stays out of this repository.
